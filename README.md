# Analyst Swarm — Мультиагентная система анализа данных

Команда из двух LLM-агентов (**Analyst** + **Reviewer**) на локальной модели **Qwen 2.5 7B**, работающая в изолированном Docker-контейнере.

## Что умеет

- Читать CSV-данные из `data/`
- Считать описательную статистику
- Выполнять SQL-запросы к CSV как к таблицам SQLite
- Строить графики (matplotlib) → PNG в `reports/`
- Генерировать Markdown-отчёты с инсайтами
- Всё **локально**, **без интернета**, **на русском языке**
